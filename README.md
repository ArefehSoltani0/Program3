🎲 Random Array Initializer – C# Console App

A simple, elegant C# program that initializes an integer array with **random values** using the `Random.Next()` method.

Ideal for beginners learning arrays, loops, and random number generation in .NET.

---

✅ Features

- 📦 Creates a fixed-size integer array  
- 🎯 Fills it with random integers in a customizable range (e.g., 1–100)  
- 🖨️ Displays the array in a clean, readable format  
- 🔧 Fully self-contained — no external dependencies  
- ✅ Compiles and runs on **.NET 6+**, **.NET Framework**, and **Mono**

---

🚀 How to Run

 Prerequisites
- [.NET SDK](https://dotnet.microsoft.com/download) (any recent version)

Steps
bash
dotnet new console -o RandomArray
cd RandomArray
# Replace `Program.cs` with the provided code
dotnet run
